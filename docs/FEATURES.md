# 符寶網 - 特色功能整理

> **定位**：全球玄門文化科普交易平台  
> **核心特色**：玄門文化 + 電商交易 + AI 賦能 + 加密支付

---

## 一、玄門文化垂直定位

### 1.1 文化科普體系

| 特色 | 說明 |
|------|------|
| 玄門百科 | 獨立百科模塊（`/baike`），系統化整理玄門文化知識條目，支持 slug 路由瀏覽 |
| 文化資訊 | 新聞資訊板塊（`/news`），持續輸出玄門文化動態、行業資訊 |
| 商品即文化 | 商品分類按玄門用途劃分（護身符、法器、香道、風水擺件、佛珠手串等），商品詳情融入文化解讀 |
| 證書認證 | 商品支持 `is_certified` 認證標記，區分正品法器與普通工藝品 |

### 1.2 儀式化商品屬性

| 特色 | 說明 |
|------|------|
| 用途標籤 | 每件商品標註玄門用途（`purpose` 字段），如鎮宅、護身、招財、辟邪 |
| 類型分類 | 商品按 `type` 區分為實物法器、虛擬服務（如遠程祈福、命名擇日） |
| 規格選擇 | 支持規格 SKU 管理（材質、尺寸、開光與否等） |

---

## 二、AI 智能助手（文化賦能）

### 2.1 流式 AI 對話

| 特色 | 說明 |
|------|------|
| 玄門知識問答 | AI 助手基於玄門文化知識庫，回答用戶關於風水、命理、法器、儀式等問題 |
| SSE 流式輸出 | 打字機式實時渲染，後端 `ReadableStream` 逐步輸出，前端 `Reader` 增量渲染 |
| 多模型切換 | 支持 DeepSeek（默認）、豆包、Kimi 三大模型，按需切換 |
| 多輪對話 | 上下文記憶，支持連續追問 |
| 思考模式 | 支持思考鏈輸出，展示 AI 推理過程 |

### 2.2 知識庫語義搜索

| 特色 | 說明 |
|------|------|
| 文檔導入 | 支持文本、URL、對象存儲 URI 多種格式導入 |
| 向量化存儲 | 文檔自動向量化，存儲為語義索引 |
| 語義檢索 | 基於向量相似度的智能搜索，而非簡單關鍵詞匹配 |
| 知識管理 | 管理後台可管理知識庫文檔的增刪改查 |

### 2.3 AI 內容生成

| 特色 | 說明 |
|------|------|
| 自動文案 | 管理後台可使用 AI 自動生成商品描述、營銷文案 |
| 多語言翻譯 | AI 輔助商品信息多語言翻譯 |
| 訓練管理 | 支持自定義 AI 訓練任務，持續優化回答質量 |

---

## 三、SOL 加密貨幣支付

### 3.1 全鏈路 SOL 支付

| 特色 | 說明 |
|------|------|
| SOL 充值 | 錢包充值默認推薦 SOL，用戶可使用 Solana 加密貨幣充值餘額 |
| SOL 提現 | 餘額提現直接到用戶 SOL 錢包地址，1% 手續費 |
| SOL 訂單支付 | 訂單支付頁面 SOL 為首選支付方式 |
| 地址驗證 | 提現時嚴格驗證 SOL 地址格式（Base58，32-44 字符） |
| 餘額安全 | 提現申請自動凍結餘額，管理員審核後才實際到賬 |

### 3.2 雙軌支付體系

| 方式 | 說明 |
|------|------|
| SOL (Solana) | 加密貨幣支付，推薦，全球可用 |
| PayPal | 傳統國際信用卡支付，Visa/Mastercard |
| 支付寶/微信 | 頁面預留，即將開放 |

## 四、多語言國際化

| 特色 | 說明 |
|------|------|
| 商品多語言 | `goods_i18n` 表存儲翻譯，API 支持 `locale` 參數動態切換 |
| API 層翻譯 | 商品列表/詳情 API 根據 `locale` 參數返回對應語言版本 |
| AI 輔助翻譯 | 管理後台 AI 翻譯接口，批量翻譯商品信息 |
| 默認語言 | 繁體中文（`zh-TW`），面向全球華人社區 |
| 翻譯降級 | 請求語言無翻譯時自動降級為默認語言，附帶 `_original` 字段 |

## 五、分銷裂變系統

| 特色 | 說明 |
|------|------|
| 多級分銷 | 支持 `parent_id` 層級分銷關係，`user_distribution` 表管理分銷員 |
| 佣金體系 | 分銷商品自動計算佣金，`distribution_config` 配置各級佣金比例 |
| 佣金管理 | `total_commission`/`available_commission`/`frozen_commission`/`withdrawn_commission` 全鏈路追蹤 |
| 邀請連結 | 每個分銷員獨立邀請碼和邀請連結，自動生成二維碼 |
| 團隊管理 | 可查看下級分銷員、團隊銷售額統計 |
| 分銷提現 | 獨立提現流程，最低 HK$100 |

## 九、安全與穩定性

| 特色 | 說明 |
|------|------|
| JWT 雙通道認證 | `Authorization: Bearer` header + `auth_token` httpOnly cookie，雙保險 |
| 防禦性編程 | API 響應 `.map()` 調用始終 `|| []` 防禦空值 |
| 圖片 URL 統一處理 | `fixImageUrl()` 統一處理 `/api/file/`、純文件名、完整 URL 三種格式 |
| Hydration 安全 | 動態內容僅客戶端渲染，避免 SSR/CSR 不一致 |
| standalone 符號連結 | uploads 目錄符號連結，確保部署不丟失上傳文件 |
| 緩存自動清理 | 每次部署自動清理 `.next` 目錄，防止 Server Action 緩存不匹配 |
